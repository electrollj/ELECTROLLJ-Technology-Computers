# ELECTROLLJ — Technology & Computers

**Powering Innovation. Connecting the Future.**

Premium static demonstration website, styled in Midnight Navy `#0F172A`, Electric Blue `#3B82F6` and White `#FFFFFF`.

## Pages
Home, Shop, Collections, IT Solutions, About, Contact, FAQ, Privacy, Terms.

## Features
Responsive navigation, client-side product search/category filters/sorting, localStorage cart and wishlist, illustrative USD prices, and demo-only contact form. All products, prices and services are concepts; no real checkout or message delivery.

## Preview
Open `index.html` in a browser. No build tooling needed. Google Fonts requires an internet connection; local fallbacks are provided.

## Publish with GitHub Pages
Upload all files and the `assets` folder to a GitHub repository, keeping `index.html` at the repository root. In **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)`, then save.

## Customize
Update product data in `assets/app.js`, styles in `assets/style.css`, and text in each HTML file. Replace the demo contact form and checkout with real backend services only after appropriate operational setup.
